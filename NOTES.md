# About the Build

## 1
The baseModel by the pydantic enforces Body validation entering the
endpoint, I only define the types, then restriction and fastapi 
automatically handles error handling without me writing code for it.

## 2
The IDs are kept in a dictionary, it also auto generated by the
_generate_next_id helper which checks the max id and increment by 1.
Then for the requirement to return the latest, I sort the ids descending
order because the later events are always on higher id compare to previous

## 3
If we were to restart the app, the entire EVENTS will be wiped out since
its only working a variable which is kept as memory, there's no persistence
